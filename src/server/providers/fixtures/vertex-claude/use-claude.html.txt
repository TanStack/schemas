<h3 id="before_you_begin" data-text="Before you begin" tabindex="-1">Before you begin</h3>

<p>Anthropic enforces policies that prohibit certain resellers from reselling their
products. If your Google Cloud billing account is managed by a prohibited
reseller, you will be unable to accept the Terms of Service or enable Claude
models. If this occurs, please contact your reseller directly.</p>
<aside class="note"><strong>Note:</strong><span> If enabling Claude models using Marketplace within an
Assured Workloads boundary, you may be required to create an exception
for <code translate="no" dir="ltr">cloudcommerceconsumerprocurement.googleapis.com</code> and
<code translate="no" dir="ltr">commerceagreement.googleapis.com</code>. For more information on the exception
process, see <a href="/assured-workloads/docs/monitor-folder#exception">Add violation exceptions
</a>.</span></aside>
<p>To use the Anthropic Claude models with Gemini Enterprise Agent Platform, you must perform the
following steps. The Agent Platform API (<code translate="no" dir="ltr">aiplatform.googleapis.com</code>) must
be enabled to use Gemini Enterprise Agent Platform. If you already have an existing project with
the Agent Platform API enabled, you can use that project instead of creating
a new project.</p>

<p>Make sure you have the required permissions to enable and use partner models.
For more information, see <a href="/gemini-enterprise-agent-platform/models/partner-models/use-partner-models#grant-permissions">Grant the required permissions</a>.</p>

<h3 id="use_the_anthropic_sdk" data-text="Use the Anthropic SDK" tabindex="-1">Use the Anthropic SDK</h3>

<p>You can make API requests to the Anthropic Claude models using the <a href="https://pypi.org/project/anthropic/">Anthropic
Claude SDK</a>. To learn more, see the
following:</p>

<ul>
<li><a href="https://docs.anthropic.com/claude/reference/messages_post">Claude messages API reference</a></li>
<li><a href="https://github.com/anthropics/anthropic-sdk-python">Anthropic Python API library</a></li>
<li><a href="https://github.com/anthropics/anthropic-sdk-typescript/tree/main/packages/vertex-sdk">Anthropic Gemini Enterprise Agent Platform TypeScript API Library</a></li>
</ul>

<p>To test a text prompt by using the Agent Platform API, send a POST request to the

<p>
  Before using any of the request data,
  make the following replacements:
</p>

<ul>
  <li><var class="edit" scope="LOCATION" translate="no">LOCATION</var>:  A <a
    href="#regions">region</a> that supports Anthropic Claude models. To use the
    global endpoint, see <a
    href="/gemini-enterprise-agent-platform/models/partner-models/use-partner-models#global">Specify
    the global endpoint</a>.</li>
  <li><var class="edit" scope="MODEL" translate="no">MODEL</var>: The <a
                        href="#model-list">model name</a> you want to use.</li>
  <li><var class="edit" scope="ROLE" translate="no">ROLE</var>: The role associated with a
    message. You can specify a <code translate="no" dir="ltr">user</code> or an <code translate="no" dir="ltr">assistant</code>.
    The first message must use the <code translate="no" dir="ltr">user</code> role.  Claude models
    operate with alternating <code translate="no" dir="ltr">user</code> and <code translate="no" dir="ltr">assistant</code> turns.
    If the final message uses the <code translate="no" dir="ltr">assistant</code> role, then the response
    content continues immediately from the content in that message. You can use
    this to constrain part of the model's response.</li>
  <li><var class="edit" scope="STREAM" translate="no">STREAM</var>: A boolean that specifies whether the response
    is streamed or not. Stream your response to reduce the end-use latency perception. Set to
    <code translate="no" dir="ltr">true</code> to stream the response and <code translate="no" dir="ltr">false</code> to return the response all at
    once.</li>
  <li><var class="edit" scope="CONTENT" translate="no">CONTENT</var>: The content, such as text, of the <code translate="no" dir="ltr">user</code> or
    <code translate="no" dir="ltr">assistant</code> message.</li>
  <li><var class="edit" scope="MAX_TOKENS" translate="no">MAX_TOKENS</var>: 
Maximum number of tokens that can be generated in the response. A token is
approximately 3.5 characters. 100 tokens correspond to roughly 60-80 words.

<p>Specify a lower value for shorter responses and a higher value for potentially longer
responses.</p>

  <li><var class="edit" scope="TOP_P" translate="no">TOP_P</var> (Optional): 
Top-P changes how the model selects tokens for output. Tokens are selected
from the most probable to least probable until the sum of their probabilities
equals the top-P value. For example, if tokens A, B, and C have a probability of
0.3, 0.2, and 0.1 and the top-P value is <code translate="no" dir="ltr">0.5</code>, then the model will
select either A or B as the next token by using temperature and excludes C as a
candidate.

<p>Specify a lower value for less random responses and a higher value for more
random responses.</p>

  <li><var class="edit" scope="TOP_K" translate="no">TOP_K</var>(Optional): 
Top-K changes how the model selects tokens for output. A top-K of
<code translate="no" dir="ltr">1</code> means the next selected token is the most probable among all
tokens in the model's vocabulary (also called greedy decoding), while a top-K of
<code translate="no" dir="ltr">3</code> means that the next token is selected from among the three most
probable tokens by using temperature.

<p>For each token selection step, the top-K tokens with the highest
probabilities are sampled. Then tokens are further filtered based on top-P with
the final token selected using temperature sampling.</p>

<p>Specify a lower value for less random responses and a higher value for more
random responses.</p>

  <li><var class="edit" scope="THINKING_TYPE" translate="no">TYPE</var>: For
  Claude 3.7 Sonnet on Google Cloud and later Claude models, to enable extended thinking mode,
  specify <code translate="no" dir="ltr">enabled</code>.</li>
  <li><var class="edit"
  scope="THINKING_BUDGET" translate="no">BUDGET_TOKENS</var>: If you
  enable extended thinking, you must specify the number of tokens that the model
  can use for its internal reasoning as part of the output. Larger budgets can
  enable more thorough analysis for complex problems and improve response
  quality. You must specify a value greater than or equal to <code translate="no" dir="ltr">1024</code>
  but less than <code translate="no" dir="ltr">MAX_TOKENS</code>.
</ul>
